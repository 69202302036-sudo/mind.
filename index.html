สร้าง Portfolio ออนไลน์ฟรีง่ายๆ ภายใน 5 นาที

1 เตรียมไฟล์เว็บไซต์

บันทึกโค้ดนี้ทั้งหมดลงในไฟล์ชื่อ index.html ไว้บนเครื่องคอมพิวเตอร์ของคุณ

2 สร้าง Repository บน GitHub

เข้าสู่ระบบ GitHub.com แล้วกดปุ่ม "New" ตั้งชื่อ Repository เช่น my-portfolio เลือกเป็น Public จากนั้นกด Create repository

3 อัปโหลดไฟล์ index.html

ในหน้า Repository คลิกเลือก "uploading an existing file" ลากไฟล์ index.html วางลงไป แล้วกดปุ่ม Commit changes

4 เปิดใช้งาน GitHub Pages

ไปที่เมนู Settings > เมนูด้านข้างเลือก Pages > ตรงหัวข้อ Branch ให้เลือกเป็น main (หรือ master) แล้วกด Save

เรียบร้อย!

รอประมาณ 1-2 นาที คุณจะได้ลิงก์เว็บไซต์สำหรับเข้าชม เช่น https://your-username.github.io/my-portfolio/ สามารถนำไปแนบในเรซูเม่ได้ทันที!
